## 什么是概率分布？

### 简单比喻

想象你在玩一个猜测游戏：

**场景 1：猜水果**
- 苹果：40% 可能性
- 香蕉：30% 可能性
- 橙子：20% 可能性
- 其他：10% 可能性

这就是一个**概率分布**！它告诉你所有可能的选项，以及每个选项的可能性（概率）。所有概率加起来等于 100%。

### 在神经网络中

神经网络的输出经常是概率分布的形式：
- 输入：一些数据
- 输出：一组概率，表示"模型认为每个选项的可能性有多大"

## 第一次概率分布：预测下一个词

### Qwen3 模型做什么？

Qwen3 是一个**语言模型**，它的核心任务是**预测下一个词**。

#### 例子

输入文字："今天天气很"

模型会输出一个**词汇表的概率分布**：

```
好       -> 35% 概率
不错     -> 25% 概率
热       -> 15% 概率
冷       -> 10% 概率
晴朗     -> 8% 概率
...      -> ...
（共 151,936 个词的概率）
```

### 技术细节

#### 代码位置
`vllm/model_executor/models/qwen3_boundary.py` 第 155-159 行：

```python
# 1. 通过 LM Head 计算词汇表的 logits（原始分数）
lm_logits = self.logits_processor(self.lm_head, hidden_states, ...)

# 2. 通过 softmax 转换为概率分布
probs = torch.softmax(lm_logits, dim=-1)
```

#### 维度说明

以 Qwen3-0.6B 为例（从 `config.json` 看到）：

```
vocab_size = 151,936（词汇表大小）
```

所以 `lm_logits` 和 `probs` 的形状是：
```
[batch_size, sequence_length, 151936]
```

每个 token 位置都会得到 151,936 个概率值，每个值对应词汇表中的一个词。

#### 什么是 softmax？

softmax 是一个数学函数，它把任意数字（可以是负数、很大的数）转换成 0-1 之间的概率，并且所有概率加起来等于 1。

**例子：**
```
原始分数（logits）: [2.0, 1.0, 0.5, -1.0]
↓ 应用 softmax
概率分布（probs）:   [0.53, 0.19, 0.13, 0.03]
```

注意：所有概率加起来 = 0.53 + 0.19 + 0.13 + 0.03 ≈ 1.0 (100%)

## 第二次概率分布：判断句子边界

### 我们添加的分类头做什么？

我们不想预测下一个词，而是想判断"**当前是否是完整句子的边界**"。

但是！我们不直接使用模型的隐藏状态，而是**使用第一步得到的词汇表概率分布作为特征**。

### 为什么这样设计？

词汇表的概率分布包含了丰富的语义信息：

- 如果"。"（句号）的概率很高 → 可能是句子结尾
- 如果"的"、"了"等词概率高 → 可能句子还没结束
- 如果停顿词（"嗯"、"啊"）概率高 → 可能是语气停顿

通过学习这 151,936 个概率的模式，分类头可以做出更准确的判断。

### 分类头的结构

#### 代码位置
`vllm/model_executor/models/qwen3_boundary.py` 第 33-52 行：

```python
class SentenceBoundaryHead(nn.Module):
    """两层 MLP，输入是 LM 概率分布"""

    def __init__(self, vocab_size: int, hidden_size: int,
                 num_labels: int, dropout: float):
        self.layer = nn.Sequential(
            nn.Linear(vocab_size, hidden_size),      # 151936 -> 512
            nn.GELU(),                                # 激活函数
            nn.Dropout(dropout),                      # 防止过拟合
            nn.Linear(hidden_size, num_labels),      # 512 -> 2
        )

    def forward(self, probs: torch.Tensor) -> torch.Tensor:
        return self.layer(probs)
```

#### 数据流

```
输入：词汇表概率分布
[151936 个概率值]
↓
第一层线性变换
[512 个特征]
↓
GELU 激活 + Dropout
[512 个特征]
↓
第二层线性变换
[2 个原始分数（logits）]
↓
Softmax（在解析时应用）
[2 个概率]
- 类别 0（未完结）：70%
- 类别 1（完整）：30%
```

### 输出解释

最终输出是一个 **2 分类的概率分布**：

```
未完结（0） -> 70% 概率
完整（1）   -> 30% 概率
```

模型认为当前 token 有 70% 的可能性不是句子结尾，30% 的可能性是句子结尾。

## vLLM 的作用：解析输出

### vLLM 做了什么？

vLLM 是一个高性能推理引擎，它帮助我们：

1. **高效计算**：加速模型推理
2. **流式处理**：支持逐 token 输入和输出
3. **输出解析**：将模型的原始输出转换成易用的格式

### 输出格式

#### 模型返回的原始数据
`vllm/model_executor/models/qwen3_boundary.py` 第 161 行：

```python
# 模型输出：拼接 boundary_logits 和 hidden_states
return torch.cat([boundary_logits, hidden_states], dim=-1)
```

形状：`[num_tokens, batch_size, 2 + hidden_size]`

例如对于 Qwen3-0.6B：
- `hidden_size = 1024`（从 config.json）
- 总维度 = 2 + 1024 = 1026

前 2 维是边界判断的 logits，后 1024 维是原始隐藏状态。

#### vLLM 如何解析
示例代码位置：`examples/offline_inference/qwen_boundary_model.py` 第 46-56 行：

```python
def decode_boundary_output(resp, num_labels: int):
    """从 vLLM 输出中提取边界判断结果"""
    if resp.outputs.data is None:
        return None

    # 1. 提取前 num_labels 维（通常是 2）
    logits = resp.outputs.data[..., :num_labels].to(torch.float32)

    # 2. 应用 softmax 转换为概率
    probs = torch.softmax(logits, dim=-1)

    return probs
```

#### 解析流程

```
vLLM 原始输出
[token_0, token_1, token_2, ...]
每个 token 包含 1026 维数据
↓
提取前 2 维
[token_0: [logit_0, logit_1],
 token_1: [logit_0, logit_1],
 ...]
↓
应用 softmax
[token_0: [prob_0=0.7, prob_1=0.3],
 token_1: [prob_0=0.4, prob_1=0.6],
 ...]
↓
找到概率最大的类别
token_0 -> 类别 0（未完结）
token_1 -> 类别 1（完整）
```

### 实际使用
示例代码位置：`examples/offline_inference/qwen_boundary_model.py` 第 82-101 行：

```python
async for resp in response:
    if resp.outputs.data is not None:
        # 使用 vLLM 提供的解析函数
        probs = decode_boundary_output(resp, num_labels)

        # 找到预测类别
        preds = torch.argmax(probs, dim=-1)

        # 处理每个 token
        for i in range(num_tokens):
            token_id = full_token_ids[processed + i]
            token_text = tokenizer.decode([token_id])
            label_id = preds[i, 0].item()  # 0 或 1
            label = BOUNDARY_LABELS.get(label_id)  # "未完结" 或 "完整"
            confidence = probs[i, 0, label_id].item()  # 置信度

            logger.info(f"Token: {token_text} -> {label} ({confidence:.3f})")
```

## 实际例子

### 场景：判断句子是否完整

输入文字（逐字符流式输入）：
```
"１２月３１日，中共中央总书记、国家主席江泽民发表新年讲话。"
```

### 逐 Token 处理过程

#### Token 1: "１"

**第一次概率分布（词汇表）：**
```
２    -> 0.35  (最可能的下一个字)
月    -> 0.15
日    -> 0.08
...
（共 151,936 个概率）
```

这个概率分布传入分类头后：

**第二次概率分布（边界判断）：**
```
未完结（0） -> 0.98  (98%)
完整（1）   -> 0.02  (2%)
```

**结论**：模型非常确定这不是句子结尾（显然，才一个字）

---

#### Token 10: "、"

**第一次概率分布（词汇表）：**
```
国    -> 0.25
中    -> 0.18
总    -> 0.12
...
```

**第二次概率分布（边界判断）：**
```
未完结（0） -> 0.95  (95%)
完整（1）   -> 0.05  (5%)
```

**结论**：顿号通常不是句子结尾，模型判断还未完结

---

#### Token 25: "。"（句号）

**第一次概率分布（词汇表）：**
```
"     -> 0.20  (可能是引用结束)
\n    -> 0.15  (可能换行)
新    -> 0.10  (可能开始新句子)
...
```

**第二次概率分布（边界判断）：**
```
未完结（0） -> 0.15  (15%)
完整（1）   -> 0.85  (85%)
```

**结论**：句号出现，模型高度确信这是完整句子的边界！

## 关键概念总结

### 1. 两次概率分布转换

| 转换 | 输入 | 输出 | 维度 | 含义 |
|-----|------|------|------|------|
| **第一次** | Token 隐藏状态 | 词汇表概率分布 | 151,936 | 预测下一个可能的词 |
| **第二次** | 词汇表概率分布 | 边界判断概率分布 | 2 | 判断是否是句子边界 |

### 2. Softmax 的作用

Softmax 把原始分数（logits）转换成概率分布：
- 所有值在 0-1 之间
- 所有值加起来等于 1
- 值越大，表示对应选项的可能性越高

### 3. vLLM 的角色

vLLM 不是"处理"概率分布，而是：
1. **加速推理**：高效运行模型
2. **管理流程**：处理流式输入/输出
3. **解析结果**：提取有用的信息（前 2 维）
4. **格式转换**：将原始 tensor 转换成易用的结果

### 4. 为什么使用词汇表概率作为特征？

传统方法通常直接使用隐藏状态（1024 维）做分类。我们的方法：

**优点**：
- 词汇表概率包含丰富的语义信息
- 模型已经学会了语言的模式（通过预训练）
- 通过这些概率，分类头能"看到"模型认为接下来最可能出现什么词
- 例如：如果标点符号概率高，更可能是边界

**缺点**：
- 维度更高（151,936 vs 1024），计算稍慢
- 需要额外的 softmax 操作

## 总结

我们的模型做了两次"猜测"：

1. **第一次猜测**：如果要继续写，下一个词是什么？
   - 输出 151,936 个词的概率分布
   - 这是 Qwen3 语言模型的原始能力

2. **第二次猜测**：根据"下一个词的概率分布"，当前是不是句子边界？
   - 输入第一次的概率分布
   - 输出 2 分类的概率（未完结/完整）
   - 这是我们添加的分类头的能力

**vLLM 的作用**：
- 让整个过程运行得很快（高性能推理）
- 支持流式处理（逐字符输入）
- 帮助解析和提取有用的输出

这就像一个两步决策过程：
1. 语言模型说："接下来最可能是这些词..."
2. 分类头说："基于这些可能性，我判断现在是/不是句子边界"

两次概率分布转换，两次"猜测"，最终得到我们想要的判断结果！
